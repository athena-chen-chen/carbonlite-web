Governed unit conversion flow

How a valid Natural Gas GJ record can calculate through an m3 factor only when a separate, approved conversion record exists.

Core priority

Direct emission factor wins. Conversion is a fallback. Missing provenance returns Unit Mismatch / Needs Review.

Primary example

Activity Natural Gas
Quantity 3 GJ
Jurisdiction Alberta, Canada
Available factor kgCO2e / m3

Event flow

Input event

Record is normalized

Activity type, quantity, unit, record year, and jurisdiction become the matching inputs.

valid unit: GJ
Gate 1

Find direct emission factor

Search only emission factors where input unit matches the record unit.

if kgCO2e/GJ exists, stop
Gate 2

Try governed conversion path

Use a different-unit emission factor only if an eligible GJ to m3 conversion record is approved.

conversion provenance required
Gate 3

Review if no approved path

The record remains saved but excluded from emissions totals.

Unit Mismatch

Three possible outcomes

Direct match

A Natural Gas kgCO2e/GJ factor exists.

  1. Select best direct factor.
  2. Do not convert.
  3. Calculate: original GJ quantity times kgCO2e/GJ.
DIRECT_UNIT_MATCH

Conversion fallback

No GJ factor exists, but an m3 factor and governed GJ to m3 conversion both exist.

  1. Preserve original 3 GJ.
  2. Persist converted m3 quantity and conversion snapshot.
  3. Calculate with kgCO2e/m3.
CONVERSION_ASSISTED

Needs review

An m3 factor exists, but the conversion record is missing, inactive, or lacks provenance.

  1. Do not invent a value.
  2. Do not treat GJ to m3 as exact.
  3. Show Unit Mismatch with available factor unit.
NO_APPROVED_CONVERSION

Current code map from audit

Existing factor schema

src/services/conversionFactors.ts has emission-factor style fields including source authority, document, URL, year, effective dates, version, confidence, verification, and lifecycle-like status.

Direct matcher

findBestConversionFactorMatch currently requires type = EMISSION and exact normalized input-unit equality before selecting a factor.

Different-unit factor detection

getCompatibleFactorUnitLabels can show that a same-activity factor exists in another valid unit, which supports the Unit Mismatch path.

Calculation evaluation

evaluateActivityRecord multiplies the original quantity by the factor value after a direct match; conversion-assisted quantity is not first-class yet.

Traceability

calculationTraceability can display a conversion if normalizedQuantity differs from the factor input unit, but it does not yet carry source-backed conversion provenance.

Persistence gap

No separate governed unit-conversion store was found in the inspected frontend services. Existing naming around "conversion factors" is used for emission factors.

This diagram intentionally avoids a numeric GJ to m3 value. That value must come from an approved, source-backed conversion record.
